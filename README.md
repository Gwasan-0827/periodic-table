## 뭐 하는 곳이에요?

118개 원소를 누르면 원자 모형과 정보가 나오고, 원소끼리 **조합**해서 물, 소금, 이산화탄소 같은 물질을 만들 수 있어요. 만든 물질은 **도감**에 모이고, 모을수록 업적이 풀려요.

- **원소 정보**: 원자 번호, 원자량, 전자 배치, 이름의 유래. 칸 뒤로 그 원소 블록(s·p·d·f)의 오비탈 모양 구름이 돌아요
- **원자 모형**: 보어 모형과 전자 구름, 크게 보기에서 오비탈 하나씩 골라 보기
- **핵 속으로**: 원자 → 원자핵 → 양성자·중성자 → 쿼크까지 확대. 글루온 끈은 Y자 빛줄기로
- **조합과 도감**: 원소를 섞어서 물질 **550종** 모으기. 결과는 실제 분자 구조식으로 그려져요
  - 실패하면 "이렇게 고쳐 봐요"로 원소 몇 개를 빼거나 더하면 되는지 알려 줘요
  - 못 찾은 카드를 누르면 힌트가 3단계로 열려요
- **분자 모형**: 막대-공 / 공간 채움 / 막대 / 2D·3D 구조식
- **분자 오비탈**: H₂, N₂, O₂, CO, 벤젠, 육중결합(Mo₂) 등은 에너지 도표와 전자 구름으로
- **광물과 유리**: 광물은 실물 결정 모양으로, 보석은 깎은 모양으로
- **이상한 물질들**: 펭귄논, 큐베인, 나노카, 피라냐 용액처럼 이름이나 모양이 특이한 것들
- **검색**: 원소 이름·기호·번호, 찾은 물질, 화학식(H2O, NaCl)까지. 화학식은 바로 조합 칸에 담겨요
- **학습**: 원소 퀴즈, 외우기, 오늘의 원소, 이온, 오비탈 단면, 미니게임
- **처음이라면**: 따라 하는 튜토리얼, 첫걸음 미션 8개, "주기율표 읽는 법"
- **업적**: 숨겨진 것 포함 60개 넘게
- **한국어 / English**: 폰이나 브라우저 언어에 맞춰 자동으로 바뀌어요

## 마스코트, 아스리엘(리엘이)

주기율표 화학 실험실의 **신입 연구원**이에요. 본인 주장으로는요.

- 원소를 누르면 옆에서 한마디씩 거들어요
- 가끔 호버보드를 타고 표 위를 순찰해요
- 가끔 하늘색 원자 커서가 돌아다니는데… 누구 커서일까요?
- **아스리엘 도감**에서 리엘이의 여러 모습을 모을 수 있어요

더 있는데, 그건 직접 찾아보세요. (힌트: 튜토리얼은 건너뛰지 마세요)
